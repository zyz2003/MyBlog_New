| Boundary | Description |
|----------|-------------|
| Nuxt layout resolution | Layout inheritance chain: admin.vue declares layout → Nuxt resolves to admin-default → child pages inherit |
| Template rendering | CSS class expansion: @apply directives replaced with inline UnoCSS utility classes — no runtime CSS compilation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-05-01 | Tampering | admin.vue layout declaration | accept | Static string 'admin-default' in definePageMeta — no user input, no injection vector. Incorrect layout name would cause Nuxt to fall back to default layout (observable error, not silent corruption) |
| T-01-05-02 | Information Disclosure | UnoCSS class replacement | accept | All UnoCSS classes are standard utility class names with no secrets or PII. Expanding @apply to inline classes makes the template more verbose but equally public |
| T-01-05-03 | Denial of Service | Removing scoped styles | accept | Removing @apply rules eliminates the compile-time CSS extraction step — marginally faster build. No new DoS vector introduced |
</threat_model>
